📜 Buku Petunjuk Perangkaian Smart Lamp

Untuk merangkai sistem lampu otomatis yang sukses, ikuti aturan logika teknis berikut dengan teliti:

  • Daya Utama (Kabel Merah / 5V): Hubungkan pin VCC pada Sensor LDR dan pin VCC pada Lampu LED menuju sumber daya 5V di Arduino Uno.
  • Kabel Netral (Kabel Abu / GND): Hubungkan pin GND Sensor dan GND Lampu LED menuju pin GND (Ground) pada Arduino.
  • Data Sensor (Kabel Hijau / SIG): Sensor LDR harus membaca data analog cahaya luar, oleh karena itu pin SIG wajib dihubungkan ke pin Analog A0 Arduino.
  • Kendali Output (Kabel Kuning / CTRL): Arduino mengirim perintah nyala/padam ke lampu lewat pin Digital D8. Hubungkan pin CTRL LED ke pin D8.
